Use your Codespace in LVCE Editor

Create, start, stop, and connect from this GitHub Pages site. Setup runs automatically through a private SSH connection.

  1. Open LVCE Editor and sign in with GitHub using the account button.
  2. Press F1 and run Codespaces: Authorize GitHub Access if you previously signed in without the Codespaces permission. Approve GitHub’s additional permission and return to the editor.
  3. Run Codespaces: Connect to Codespace and select a Codespace. It will start if needed. To create one, run Codespaces: Set Up a Codespace, search your GitHub repositories, select one, and confirm creation. You can also choose Enter a repository manually… and type owner/name.
  4. Wait for setup and connection. Progress appears in the Codespaces Output panel. No terminal command or public port is required.
  5. Run Codespaces: Stop Codespace when finished. Disconnect cancels setup or closes the connection but leaves GitHub compute running.

GitHub compute and storage charges can apply. Creation uses GitHub’s default machine and devcontainer settings. The runtime currently needs a Linux x64 Codespace with an SSH server, Bash, curl, tar, and sha256sum; GitHub’s default image supports this.

If authorization fails, run Authorize GitHub Access again. GitHub billing limits and organization policies can also prevent creation or startup. Custom devcontainers without SSH need the sshd feature.

If GitHub cannot start an SSH server

A Codespace can be running without an SSH server in its custom container. Run Codespaces: Open in Browser to open GitHub's editor. For a Debian/Ubuntu devcontainer, add this entry to the features object in .devcontainer/devcontainer.json, preserving the existing settings: 

"ghcr.io/devcontainers/features/sshd:1": { "version": "latest" }

Then run Codespaces: Rebuild Container in GitHub's editor. Preserve work outside /workspaces before rebuilding. Installing openssh-server manually requires administrator access and only repairs the current container. LVCE can install its runtime after SSH works.

The LVCE backend must be running the Codespaces-enabled version. Implementation and current limits.
