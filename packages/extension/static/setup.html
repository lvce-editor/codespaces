Use your Codespace in LVCE Editor

Your files and tools run in GitHub Codespaces. LVCE runs in your browser.

  1. Open LVCE Editor and sign in using its account button.
  2. Open the command palette (F1) and run Codespaces: Set Up a Codespace. Copy the generated command.
  3. Open or create a Codespace on GitHub. In its terminal, run the command from your workspace directory. Setup requires Linux x64 and Node.js 24 or newer, and downloads a verified LVCE runtime.
  4. In the Codespaces Ports tab, forward port 3774 and set its visibility to Public. The gateway still requires your LVCE account. Only publish this gateway port; keep the internal backend private.
  5. Return to LVCE, run Codespaces: Connect to Codespace, and enter the codespace name or its forwarded HTTPS URL.

Keep the setup terminal running. Sessions last one hour. To reconnect after a reload, run Connect again. Organizations that prohibit public forwarded ports cannot use this connection method.

This first version uses the existing LVCE login without changing its backend. Codespace creation and startup happen on GitHub because the current LVCE OAuth integration does not grant Codespaces API access. Private-port transport and automatic remote setup are not implemented.
